HOW IT WORKS

Set up your auction in three steps

  1. Create teams and auction rules. Set team budgets, player limits, categories, and bidding details.
  2. Register or add players. Collect player information using a shareable registration form or add players directly.
  3. Start bidding and share the live view. Run the auction and let others follow the action through Cricbids.

Cricket auction software FAQs

Can I run an IPL-style player auction online?

Yes. Cricbids gives organizers live bidding controls, team management, player records, and a public auction view.

Can players register online?

Yes. Share your player-registration link so participants can submit their details for the correct tournament.

Can others watch the auction live?

Yes. Each public auction can be shared with a unique watch link for live bids and results.
